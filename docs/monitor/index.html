Each role sees its own screen and its own way to handle an outage. Incidents replay faults from the project's OpenDSS fault sweep (including intermittent arcing HIFs ≥ 100 Ω, independent per-zone loading with pre/post drift, and CT/PT noise); the fault-zone prediction comes from the ML model tested on buses it never saw in training.
